General Instructions

  1. Download the template files provided with this exam (including the database script and the .sql / .py template files). Save them in a working directory on your machine.
  2. Complete all tasks using the specified files and filenames. Do not rename any of the template files.
  3. When you have finished all tasks, compress all required answer files into a single archive named <your_candidate_id>_data_engineer_partB.zip.
  4. Upload this .zip file as your final answer for Part B in Moodle.

After reading these instructions, complete the tasks below in order.

Task 1 – Import the HR database

  1. Use HeidiSQL (or the MariaDB command-line client) to import the database from the file hr_install_maria.sql.
  2. The script will create a database user with:
    • Username: hr
    • Password: data@2040
    You should use these credentials in later tasks.

Task 2 – Data verification queries

Write SQL statements that verify the integrity and consistency of the imported data. For each query:

  • Print the results of the query.
  • Use the exact column aliases specified below.
  • Once you have verified the output, copy your final queries into the file task2_verify.sql.
  1. Task 2.1 – Table record counts
    Count how many records exist in each of the following tables: employees, departments, jobs, and locations.
    Return a single row with the following columns:
    • employees_count
    • departments_count
    • jobs_count
    • locations_count
  2. Task 2.2 – Invalid employee departments
    Check that every employee has a valid department (that is, department_id is present in the departments table).
    Return a single number aliased as:
    • invalid_departments
  3. Task 2.3 – Invalid department locations
    Verify that all department locations exist in the locations table.
    Return a single number aliased as:
    • invalid_locations
  4. Task 2.4 – Range of hire dates
    Find the range of employee hire dates (earliest and latest).
    Return two columns:
    • earliest_hire
    • latest_hire
  5. Task 2.5 – Top regions by number of employees
    List the top 2 regions by number of employees working in them.
    Return the following columns:
    • region_name
    • num_employees

Task 3 – Transformation queries

In this task you will write several analytical queries. The requirements are:

  • Write each query in the order given below.
  • You must not create or modify any database objects (no CREATE, ALTER, etc.).
  • Each answer must be a single SELECT statement.
  • Write your final answers in the file task3_transform.sql.
  1. Task 3.1 – Department salary summary
    Write a query that returns, for each department with at least 5 employees:
    • department_id
    • department_name
    • num_employees
    • avg_salary
    • total_salary
    Sort the output by:
    1. total_salary in descending order
    2. department_id in ascending order
  2. Task 3.2 – Region salary summary
    Write a query that returns, for each region:
    • region_name
    • num_employees
    • avg_salary
    Sort the output by avg_salary in descending order.
  3. Task 3.3 – Top job titles by employee count
    Write a query that lists the top 5 job titles with the highest number of employees, showing:
    • job_title
    • num_employees
    • min_salary
    • max_salary
    Sorting requirements:
    1. num_employees in descending order
    2. job_title in ascending order
    Limit the results to 5 rows.
  4. Task 3.4 – Employees with most job changes
    Using the job_history table, write a query that returns the top 5 employees who have the highest number of job changes, showing:
    • employee_id
    • full_name (concatenate first_name + space + last_name)
    • num_job_changes
    • max_salary
    Sorting requirements:
    1. num_job_changes in descending order
    2. employee_id in ascending order
    Limit the results to 5 rows.

Task 4 – Python data munging and reporting

In this task, you will write Python code that connects to the hr database using mysql.connector and pandas. All printed outputs must follow the exact labels shown. Write all your code in a single file named task4_munge.py.

Task 4.1 – Region salary aggregation

  1. Retrieve each region’s total salary and average salary using a join across the following tables: employees, departments, locations, countries, and regions.
  2. Replace any NULL region names with the string "Unknown".
  3. Print exactly the following two lines (with your calculated values): 
    TOTAL_EMPLOYEES=<int>
AVG_SALARY=<float with 2dp>
  4. Save the aggregated DataFrame to out/region_salary.csv with the columns:
    • region_name
    • total_salary
    • avg_salary

Task 4.2 – Text-only bar chart and JSON summary

Using the cleaned DataFrame from Task 4.1 (in the same Python file), write code that:

  1. Prints a text-only bar chart titled AVG_SALARY_BY_REGION.
  2. For each region, print one line with:
    • The region name, left-aligned to 12 characters.
    • A pipe character: |
    • A number of # symbols, one for every 1000 dollars of average salary.

    Example (format only – values will differ):

    AVG_SALARY_BY_REGION
Europe      |##########
Asia        |#####
Unknown     |##
  3. Print a one-line JSON summary in the following format: 
    {"summary":{"highest_region":"<name>","avg_salary":<float>}}
